# COVID RNA-seq figure analysis

This repository contains R scripts for the COVID/Flu/Mock RNA-seq figure analysis.

## Contents

- `figure2.r`: MultiQC-based sequencing and alignment QC figure.
- `figure3.r`: DESeq2 sample structure, PCA, distance heatmap, and dendrogram figure.
- `figure4.r`: DESeq2-based Flu-COVID and Young-Aged candidate gene visualization.
- `figure5.r`: mRNA versus lncRNA log2 fold-change comparison across time.

## Notes

The scripts use absolute paths for the local analysis directories under `/Users/hiuchi/Dropbox/Research/covid`.
Input tables and generated outputs are not tracked in this repository.
